## Why this exists

Diagrams are arguments. The shape should BE the meaning. This skill teaches your AI agent to draft Excalidraw JSON that passes the **Isomorphism Test** (would the structure alone communicate the concept?), runs a **taste gate** (delete until density ~4/10), and includes **evidence artifacts** (real code snippets, actual API names, concrete formats — not placeholder text). Twenty-nine progressive type references cover architecture through data-platform security matrices — including evidence pipelines and engineered comparisons.

This methodology drew **77 diagrams** for the published book *From Copilot to Colleague*. A curated source set ships in the repo; the full gallery is on the book site, with local samples at [/examples](/examples) and the competitive proof at the [web gallery](https://excalidraw-skill-pack.vercel.app/gallery/).
