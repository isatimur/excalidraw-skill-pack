## MCP

`generate_diagram_prompt` accepts `diagram_type` (e.g. `evidence`, `flywheel` → `loop`) and splices the matching type reference plus the taste gate into the agent prompt. See [MCP tool reference](/mcp/tool-reference).

## Competitive context

Compared with [diagram-design](https://github.com/cathrynlavery/diagram-design) (editorial HTML+SVG), this pack keeps typed progressive disclosure — and ships editable `.excalidraw`, theme packages, and a render-inspect loop. Full write-up: [vs diagram-design](https://excalidraw-skill-pack.vercel.app/vs-diagram-design/).
