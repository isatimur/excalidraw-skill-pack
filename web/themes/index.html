Themes

Portable visual systems for Excalidraw diagrams: palette tokens, typography, element defaults, and optional layout instructions. Agents and renderers share the same contract.

default-sketchy

Bundled baseline. Friendly, general-purpose, portable.

stripe-press

Editorial and book-grade. Strong for explainers and polished essays.

notion

Rounded, off-white, workspace-style diagrams.

whiteboard

Low-fi and bright. Useful for brainstorming sketches.

dark

Inverted contrast for dark docs, talks, and technical decks.

Use a theme

Render with Node:

npx @excalidraw-skill-pack/render diagram.excalidraw --theme stripe-press

Create a custom theme with the theme scaffolder, or read the theme manifest spec.
