# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| Latest npm/PyPI release on `main` | Yes |
| Older tagged releases | Best effort |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately by emailing the repository owner (see GitHub profile) or using GitHub's **Private vulnerability reporting** if enabled on the repository.

Include:

- Description of the issue and impact
- Steps to reproduce
- Affected packages (`@excalidraw-skill-pack/mcp-server`, `render`, themes, install adapters, etc.)
- Suggested fix if you have one

We aim to acknowledge reports within 7 days and coordinate disclosure.

## Scope

In scope: this repository's packages, MCP server, render pipeline, install scripts, and published site content served from `web/`.

Out of scope: upstream Excalidraw, Playwright/Chromium, or third-party agent hosts.
