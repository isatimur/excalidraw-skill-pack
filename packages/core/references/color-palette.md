# Color Palette

Colors live in the **active theme’s** `palette.md`. The bundled default is `themes/default-sketchy/palette.md`.

Read the active palette before drawing. Do not invent colors or use values outside its approved roles.

Use semantic categories—background/surface, primary and secondary emphasis, neutral structure, text hierarchy, status or decision states, and evidence artifacts—for their stated purpose. Evidence-artifact colors also come from the active theme.
