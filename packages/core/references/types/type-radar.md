# Radar / spider

**Best for:** multi-axis capability comparison.

## Layout conventions
Web/spoke grid with one polygon or labeled axes.

## Excalidraw pattern
Ellipse as boundary; axis labels outside.

## Connectors & routing
Consistent axis order clockwise.

## Anti-patterns
More than 8 axes.

## Budget
