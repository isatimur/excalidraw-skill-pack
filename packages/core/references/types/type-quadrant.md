# Quadrant

**Best for:** two-axis positioning, prioritization matrices.

## Layout conventions
Axes as free-floating labels. Items as ellipses or small rectangles in quadrants.

## Excalidraw pattern
Light quadrant grid optional; accent only the hero item.

## Connectors & routing
Label axes with what increases/decreases on each dimension.

## Anti-patterns
Exact numeric scores (use scatter or a table).

## Budget
≤8 positioned items.
