# Quadrant

Use a quadrant when two qualitative axes make the placement itself meaningful. Use active-theme `palette.md` colors semantically; color must not replace axis meaning.

## Layout
- Draw two structural lines crossing at a clear origin; label both axis poles with free-floating text.
- Place named items with enough spacing to make relative position credible.
- Frame only a highlighted recommendation or decision region.

## Excalidraw pattern
- Use `line` elements for axes and small colored markers or minimal labels for observations.
- Add dotted leader lines only when a label cannot sit beside its point.
- Skeleton containers are exceptional: reserve them for the recommended zone, not every point.

## Avoid
- Arbitrary placement, unlabeled axes, four equal boxes full of prose, and precise-looking coordinates without evidence.

## Budget
4–9 plotted items. Use a table if exact scores are the decision.
