# IT current-state

**Best for:** legacy landscape, modernization snapshots.

## Layout conventions
Legacy on left, target/SaaS on right; bridges in middle muted.

## Excalidraw pattern
Rectangles per system; batch/API arrows labeled.

## Connectors & routing
Left→right time or maturity progression.

## Anti-patterns
Future-state detail (split diagram).

## Budget
≤8 systems.
