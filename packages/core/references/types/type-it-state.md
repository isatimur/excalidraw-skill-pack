# IT current-state

**Best for:** legacy landscape, modernization snapshots.

## Layout conventions
Legacy on left, targets on right; ESB/bridge in the middle as the accent finding.

## Excalidraw pattern
Fan ≥3 sources into the bus on an orthogonal rail; fan ≥2 targets out; name the choke in a caption. Draw the hoped bypass as a dashed fantasy path so the audit names what isn't live.

## Connectors & routing
Shared vertical rails into/out of the ESB — no converging diagonals.

## Anti-patterns
Wallpaper of apps with no single finding; one lonely SaaS that understates the throat; a bypass drawn as if it already ships.

## Budget
≤8 systems.
