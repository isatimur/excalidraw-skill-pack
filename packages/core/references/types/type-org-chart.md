# Org chart

**Best for:** reporting lines, ownership, routing.

## Layout conventions
Top-down hierarchy. Single reporting tree per diagram.

## Excalidraw pattern
Rectangles for roles; downward arrows.

## Connectors & routing
Center children under parent.

## Anti-patterns
Matrix reporting without annotation.

## Budget
≤10 nodes.
