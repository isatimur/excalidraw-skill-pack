# Data flow

**Best for:** role-scoped pipelines, analytics paths.

## Layout conventions
Stages left→right; role eyebrow as free-floating text above.

## Excalidraw pattern
Rectangles per stage; solid transform arrows.

## Connectors & routing
Label stage outputs briefly.

## Anti-patterns
Generic cloud icons without names.

## Budget
≤6 stages.
