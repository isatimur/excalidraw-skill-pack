# Bar chart

**Best for:** categorical comparison, quarterly snapshots.

## Layout conventions
Baseline at bottom; bars upward. Accent the bar you want read first. Two or three muted gridlines with tick labels, plus the value above each bar.

## Excalidraw pattern
Rectangles as bars; category labels below; gridlines as thin `line` elements; dashed avg line; prior-year grey stubs left of live bars so YoY is visible.

## Connectors & routing
Even spacing; shared baseline.

## Anti-patterns
3D effects or gradient fills; bars with no scale; a YoY caption with no prior-year mark.

## Budget
≤8 categories.
