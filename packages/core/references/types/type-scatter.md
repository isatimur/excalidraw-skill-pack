# Scatter plot

**Best for:** distribution, correlation clusters.

## Layout conventions
Ellipses as points; optional trend callout.

## Excalidraw pattern
Small ellipses; accent outliers only.

## Connectors & routing
Label axes with measured dimensions.

## Anti-patterns
Dense point clouds (aggregate or table).

## Budget
≤12 points.
