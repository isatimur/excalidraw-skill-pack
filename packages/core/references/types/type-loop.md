# Flywheel Loop

Use a loop when each stage reinforces the next and a hub explains the compounding mechanism. Use active-theme `palette.md` colors for stages, hub, and outcome.

## Layout
- Put the causal engine in a central hub; arrange 3–6 stages around it clockwise.
- Make the return arrow visually explicit. Add free-floating annotations that name the gain at each transition.
- Use a frame for external inputs or outcomes if they are not part of the loop.

## Excalidraw pattern
- Skeleton circles/rectangles may have bound labels; the hub should be visually dominant.
- Use curved-looking multi-segment orthogonal arrows that route outside stage boxes; avoid a generic circular arrow through labels.
- Add evidence cards for a real metric or feedback signal.

## Avoid
- Calling a one-way process a flywheel, omitting the return mechanism, and equal visual weight for hub and stages.

## Budget
3–6 stages plus one hub. Split supporting mechanics outside the cycle.
