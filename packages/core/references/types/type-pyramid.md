# Pyramid / funnel

**Best for:** ranked hierarchy, funnel drop-off.

## Layout conventions
Apex = most abstract/strategic. Widening bands downward.

## Excalidraw pattern
Stacked rectangles with decreasing width upward.

## Connectors & routing
Top-down reading order.

## Anti-patterns
Equal-width bands (that's layers).

## Budget
3–5 tiers.
